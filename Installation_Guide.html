Installation Guide

📥 How to Install the App

1

Download the FASTable.apk file

2

Open File Manager on your phone

3

Go to Downloads folder

4

Tap on FASTable.apk to install

5

If prompted, allow "Install from unknown sources"

⚠️ Important: Email Verification

After signing up, the verification email might go to your SPAM/JUNK folder. Please check there if you don't see it in your inbox!
