# 📱 FASTable - Installation Guide

---

## 📥 How to Install

1. **Download** the `FASTable.apk` file

2. Open **File Manager** on your phone

3. Go to **Downloads** folder

4. Tap on **FASTable.apk** to install

5. If prompted, allow **"Install from unknown sources"**

---

## ⚠️ Important: Email Verification

After signing up, check your **SPAM/JUNK folder** for the verification email!
